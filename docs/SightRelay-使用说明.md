# Sight Relay 使用说明

Sight Relay 是一套“Capture 截图 + Server 解析 + 浏览器展示”的自托管题目解析工具。Capture 可以在后台运行，截图上传后，PC 或手机浏览器会实时显示图片、解析状态和 Markdown 答案。

## 使用前准备

Sight Relay 不提供公开注册。首次使用前，请向管理员获取：

- Server 地址，例如 `https://ot.sunyibud.online`；
- 网页登录账号和密码；
- 管理员为当前电脑创建的 Capture 设备 ID 和 Token。

正式发行包通常包含：

- `SightRelay.dmg`：macOS 安装包；
- `SightRelay-Windows-portable.zip`：Windows 绿色版。

也可以从 [Gitea Releases](https://git.sunyibud.online/sunyibud/sight-relay-release/releases) 下载最新版本。

## 1. 登录网页

1. 在电脑或手机浏览器打开管理员提供的 Server 地址。
2. 输入账号和密码登录。
3. 登录后进入主界面；同一账号可以同时在多个浏览器中打开。

Capture 上传后，已登录的主界面通过 WebSocket 自动更新，不需要手动刷新。

管理员账号还可以打开“设置”页面，管理用户、Capture 设备、LLM 配置和使用记录。普通用户不会显示管理员菜单，只能看到自己的 Capture 设备入口。

## 2. 安装和启动 Capture

### macOS

1. 打开 `SightRelay.dmg`，将 `SightRelay.app` 拖入“应用程序”。
2. 启动 Sight Relay。
3. 首次截图时，在“系统设置 → 隐私与安全性 → 屏幕录制”中允许 Sight Relay。
4. 授权后完全退出并重新启动客户端。

macOS Capture 实际始终截取主显示器，不支持在多显示器之间切换。配置界面的显示器字段仅为跨平台兼容保留。

如果使用自定义鼠标按键，还需要在“系统设置 → 隐私与安全性 → 输入监控”中允许 Sight Relay；只使用 `Option+A` 不需要输入监控权限。

关闭窗口后客户端会继续留在菜单栏。使用 `Command+Q` 或菜单栏“退出”才会完全退出。

每次启动时客户端会在后台检查新版本。发现新版本时，窗口顶部会出现“下载更新”按钮，点击后打开 Release 页面，由用户手动下载安装；网络不可用不会影响截图。

### Windows

1. 解压 `SightRelay-Windows-portable.zip`，不要直接在压缩包内运行。
2. 保留解压目录中的全部文件。
3. 双击 `SightRelay.exe` 启动。
4. 如果提示缺少 WebView2，请安装 Microsoft Edge WebView2 Runtime。

Windows 支持选择要截取的显示器，也支持自定义鼠标按键，不需要 macOS 的输入监控权限。关闭窗口后客户端继续在系统托盘运行，使用 `Ctrl+Q` 或托盘“退出”完全退出。

## 3. 创建和绑定 Capture 设备

管理员操作：

1. 登录网页，进入“设置 → Capture设备”。
2. 创建一个唯一的设备 ID，例如 `mac-home` 或 `windows-office`。
3. 生成设备 Token，并立即复制保存。

每台电脑必须使用独立的设备 ID 和 Token。重新生成 Token 后，旧 Token 会立即失效。

在 Capture 的“连接设置”中填写：

| 配置项 | 内容 |
| --- | --- |
| Server 地址 | 管理员提供的完整地址，例如 `https://ot.sunyibud.online` |
| 设备 Token | “Capture设备”页面生成的完整 Token |
| 设备 ID | 与设备页面完全一致 |
| 显示器 | Windows 选择目标显示器；macOS 保持默认即可 |

点击“保存配置”，等待连接状态变为绿色。粘贴 Token 时不要添加引号、空格或换行。

## 4. 设置截图范围

默认截图范围是完整屏幕：macOS 为主显示器，Windows 为选定显示器。

1. 在 Capture 中点击“设置捕获范围”，也可以从菜单栏/托盘打开。
2. 拖动选框内部移动位置。
3. 拖动边缘或四角调整大小。
4. 按 `Enter` 保存，按 `Esc` 取消。

后续快捷键截图会使用保存后的范围。范围编辑期间会暂停截图。

## 5. 单题截图

默认快捷键：

| 用途 | macOS | Windows |
| --- | --- | --- |
| 单题立即解析 | `Option+A` | `Alt+A` |

按下快捷键后，Capture 会截取当前范围并上传，Server 创建单题解析任务。鼠标自定义按键也只触发这个流程。

Capture 界面中的“快捷截图总开关”“键盘触发”“鼠标触发”可以分别控制触发方式；“测试截图”只用于检查当前截图和上传链路。

## 6. 多页题目组

题目组用于一张截图不足以表达完整题目的情况，例如题干、条件、选项或代码分散在不同页面。页面不要求连续，允许重复和重叠，Server 会把所有图片作为同一道题的补充证据。

| 用途 | macOS | Windows |
| --- | --- | --- |
| 截图加入题目组 | `Option+S` | `Alt+S` |
| 提交已有题目组并开始解析 | `Option+Z` | `Alt+Z` |
| 取消并清空未提交题目组 | `Option+X` | `Alt+X` |

操作步骤：

1. 在第一处内容按 `Option+S` / `Alt+S`。图片会先上传，但不会开始解析。
2. 切换到其它补充内容，继续按 `Option+S` / `Alt+S`。
3. 所有图片加入后，按 `Option+Z` / `Alt+Z` 提交现有题目组。
4. 提交快捷键不会再次截图；如果当前页面也属于题目内容，应先追加，再提交。
5. 尚未提交时按 `Option+X` / `Alt+X` 会取消关联并清空题目组。

题目组 Prompt 会合并题干、条件、公式、图表和代码，对重复内容去重；发现图片冲突或关键信息无法辨认时会明确说明，不会自行猜测。

## 7. 查看图片和解析

主界面会显示：

```text
上传 → 解析 → 完成
```

题目组会有“题目组 · N 页”标识。PC 端左侧一次显示一张图片，图片下方用“上一页 / 下一页”切换；手机端在图片查看弹窗中切换。点击图片仍可放大。

右侧或下方显示整道题的统一 Markdown 解析结果，不会为每张组内图片分别生成答案。

“设置 → 图片历史”会显示历史图片和解析摘要。点击某项可以查看完整解析；题目组项目会显示题目组标签、页数和组内图片切换。

## 8. 管理员 LLM 配置

管理员进入“设置 → LLM配置”后可以分别维护：

- 单题 Prompt：用于 `Option+A` / `Alt+A` 和鼠标触发；
- 题目组 Prompt：用于 `Option+S` / `Alt+S` 提交的题目组。

两套 Prompt 独立保存并支持热切换。保存后新任务立即使用新配置，不需要重启 Server；正在运行的任务不会被强制改写。

管理员还可以选择 OpenAI、DashScope、DeepSeek、Kimi、智谱、MiniMax 或自定义 OpenAI 兼容供应商，并分别配置 Base URL、代理、模型、推理参数和 API Key。

## 9. 常见问题

### Capture 显示认证失败

检查 Server 地址、设备 ID 和 Token 是否完全匹配。若管理员重新生成过 Token，必须使用新 Token 并重新保存配置。

### 快捷键没有反应

确认 Capture 仍在菜单栏/托盘运行，并检查“快捷截图总开关”和“键盘触发”是否开启。还要检查快捷键是否被其它软件占用。

### macOS 截图权限问题

在“屏幕录制”中允许 Sight Relay，完全退出客户端后再启动。自定义鼠标按键还需要“输入监控”权限。

### 鼠标按键无法触发

确认鼠标触发开关已开启并重新录入按键。鼠标管理软件可能把侧键改成键盘快捷键；请先取消该映射。左键和右键建议使用双击，侧键和中键通常适合单击。

### 题目组没有开始解析

确认每张图片使用的是 `Option+S` / `Alt+S`，最后使用的是 `Option+Z` / `Alt+Z`。提交不会自动截取当前页面，误按 `Option+X` / `Alt+X` 后需要重新加入图片。

### 上传失败或图片过大

Server 单张图片上传上限为 10 MiB。检查网络、Server 地址、设备 Token 和本地/MinIO 存储配置。

### 网页没有实时更新

检查浏览器与 Server 网络连接，以及反向代理是否正确转发 `/api/v1/ws` 的 WebSocket Upgrade。Capture 状态变绿后再重新打开主界面。

## 10. 安全提示

- 不要把账号密码、设备 Token、LLM API Key 或 MinIO 密钥发送给无关人员。
- 不要提交 `.env`、数据库和上传图片。
- 公网部署必须使用 HTTPS，并设置高强度管理员密码。
- 截图前确认范围内没有密码、验证码、密钥或其它敏感信息。
